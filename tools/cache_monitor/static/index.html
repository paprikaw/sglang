Weight 是节点共享的 CPU 模型缓存，每个节点只计一次。GPU 卡片展示硬件与逻辑布局，不表示每张卡各存一份 CPU weight。KV 当前统计节点 /dev/shm 中的 checkpoint 文件；「逻辑量」表示文件 / shard 大小，「resident」表示已验证仍在 RAM 的量。活跃引擎的 HiCache host pool 单独显示，未接入遥测时为「—」。未知值不会按 0 计入已测总量。

总览只计入本次可达的在线节点。历史、已取消和不可达节点不计入总量；缓存明细是逻辑布局，并非物理地址图。物理 GPU 映射没有证据时，单独显示逻辑 rank。页面只读取状态，不加载、清理或迁移缓存。
