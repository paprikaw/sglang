# AgentX：按原始会话家族拆分布局差异

仅纳入整组验收通过、三轮完整的同协议布局。每个数是三轮算术平均；C128先对同一家族的16份副本取均值，副本不作为16种独立工作负载。

**这是同一混合回放中的事后分解。** 不同家族共享排队与缓存压力；不能将各家族最佳布局拼接成动态路由收益，也不能把家族ID当作可泛化的在线预测器。根会话时间仍是压缩回放墙钟，见[时间协议](../TIMING_AUDIT.md)。
