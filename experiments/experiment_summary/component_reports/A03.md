## 测了什么与主要结果

同一组请求分别使用四个单卡 Attention 副本、两个双卡 Attention 副本、一个四卡 Attention 副本。测试组合覆盖 1、2、4 个请求，已缓存前缀 1024、12288、131072 token/请求，以及本轮处理 1、16、512 token/请求；只有表中实际列出的 8 种请求组合，不是全部组合。

一个请求、GPU 已缓存前缀 12288 token、新增 Prefill 输入 512 token 时，三种布局的耗时依次为 4.4892、2.2533、1.1571 毫秒。四请求的已测组合中，布局差异不超过 2.55%。

本轮处理 1 token 的点使用 Decode 内核，16/512 token 使用 Prefill/Extend 内核。CUDA Graph 开启。一个请求分配给一个副本时，其他副本确实没有请求；计时不含张量并行通信。
