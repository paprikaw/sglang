# C01 · A100：Attention 与 Expert 的平台边界

## 测了什么与主要结果

Attention 分支在单节点四卡内做张量并行：Decode 每请求处理 1 token，已缓存前缀为 1024/16384/49152 token，请求数从 1 到 128 选点；Prefill 另扫描每请求新增输入量，并检查 127/128/129 token 的分块边界。Expert 分支在另一个四卡节点独立测均衡路由。

4 请求、每请求 GPU 已缓存 16384 token 时，Prefill 新增输入从 128 增至 129 token，Attention 从 1.4684 增至 2.9133 毫秒。固定每卡 40 个活跃专家，全局唯一新增 token 从 20 增到 256 时，Expert 从 0.3564 增到 0.3727 毫秒。

专家分支在路由前去除来源复制：全局每个唯一 token 命中 8 个专家，均衡后每卡平均收到唯一 token 总数的两倍配对行。两分支的节点与 L2 协议不同，不可相加求整层占比。
