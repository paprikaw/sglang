## 测了什么与主要结果

每次固定 2 个请求。每请求 GPU 已缓存前缀为 0、1024、10240、196608 token；本轮每请求处理 1、16、256、512 个 token，共 16 组。处理 16/256/512 token 时使用 Prefill/Extend；处理 1 token 且已有前缀时使用 Decode；没有前缀且仅 1 token 的点是 Extend 边界控制。

每请求已缓存 10240 token、本轮新增 16 个输入 token 时，Attention、专家、通信的事件跨度中位数分别为 0.9923、0.2877、0.3604 毫秒。表中发给专家与取回结果分别列出。

前缀 KV 已位于 GPU；关闭 CUDA Graph，强制 DeepEP 低延迟路径。Attention 与专家输入独立，不是完整 Transformer 层；事件跨度可能含 CPU 提交空档，不等于纯 GPU 忙碌时间。
