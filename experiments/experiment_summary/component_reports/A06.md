## 测了什么与主要结果

固定前缀 KV 已在 GPU，主要测每请求新增 128 个 Prefill 输入 token，另有新增 256 token 的控制点。请求数在 1–16 范围选点；前缀包含均匀 15000 token、混合 10000/20000 token、混合 1000/29000 token，以及每请求 49152 token。

每请求已缓存 49152 token、新增 128 token 时，3 请求为 4.3438 毫秒，4 请求为 4.3407 毫秒。增加一条请求基本没有增加单层耗时；这不是完整模型的吞吐或容量结论。

四卡 Attention 张量并行、CUDA Graph 开启。7 个点校准模型，12 个点留出验证；测量耗时与预测耗时分列，不把预测当实测。
