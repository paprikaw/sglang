## 测了什么与主要结果

单张 A100 常驻 GLM 的 40 个专家，使用真实 INT4 权重。实际交给本 GPU 专家计算的 token–专家配对行数为 8、32、128、512、2048、8192；活跃专家数为 1、2、4、8、16、32、40，保留 37 个有效组合。

实际配对行数不超过 128 且活跃专家不超过 16 时，耗时约 0.25 毫秒。固定配对行数，分散到更多专家通常会增加成本；并非增加了同样倍数的有效计算量。

这里一行表示一个 token 在一个专家上的一次计算；同一个 token 命中多个专家会形成多行。不是请求数或唯一 token 数。旧测试从四份物理来源构造输入；CUDA Graph 关闭，不含 Attention 或通信。
