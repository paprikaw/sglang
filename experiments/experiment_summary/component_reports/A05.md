## 测了什么与主要结果

比较 GPU 已缓存前缀为 10000 token 的单请求、已缓存前缀为 20000 token 的单请求，以及两者同时合批。每个请求本轮分别新增 64 或 128 个 Prefill 输入 token；不是 Decode。

每请求新增 64 token 时，两条单请求分别耗时 0.8980、1.7725 毫秒；合批耗时 1.7638 毫秒。合批时间约等于较慢的那条请求，而不是两条时间之和。

四卡 Attention 张量并行，CUDA Graph 开启，前缀 KV 已在 GPU。单请求耗时相加是派生比较，不是直接测量的两次串行调用。
